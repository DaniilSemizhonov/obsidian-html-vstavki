# HTML-вставки

Плагин Obsidian, который встраивает HTML-файлы (например, тренажёры и решения, которые делает Claude) прямо в заметку.

## Как пользоваться

1. Положите `.html` в хранилище.
2. В заметке напишите `![[файл.html]]`.

- Высота вставки подстраивается под содержимое. Фиксированная высота: `![[файл.html|600]]`.
- Скрипты работают: интерактивные тренажёры, KaTeX, шрифты из интернета.
- Тема страницы следует теме Obsidian (`prefers-color-scheme` и `data-theme`), переключение подхватывается сразу.
- Прогресс, который страница сохраняет в `localStorage`, плагин хранит у себя и синхронизирует вместе с хранилищем.
- Внешние ссылки открываются в браузере.
- Клик по `.html` в проводнике открывает страницу во вкладке; во вставке есть кнопка «Открыть во вкладке».

## Безопасность

Страница работает в изолированном iframe (`sandbox` без `allow-same-origin`): она не видит Obsidian, файлы хранилища и данные других страниц.
